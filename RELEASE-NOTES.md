# Release Notes

User-facing changes per runtime version, newest first. Wallpaper Workshop
descriptions cite these entries verbatim in their Update Log, so the wording
stays in end-user language — what changed for the person using the wallpaper,
not how the code was rearranged.

## 0.4.1
- en: Fixed a wallpaper showing dialogue subtitles without voice on some characters — dialogue that emits only a subtitle event now also plays the line's voice.
- zh-cn: 修复部分角色壁纸对话只有字幕没有语音的问题——仅触发字幕事件的对话现在也会播放对应语音。

## 0.4.0
- en: Added an Eco quality preset (720p / 2K / 30 FPS) for lower-end machines — a lighter visual option that reduces GPU load.
- zh-cn: 新增「节能」画质档（720P / 2K / 30 FPS），面向低配设备——更轻量的画面选项，降低显卡负载。

## 0.3.2
- en: Removed the placeholder "OFFLINE EDITION · 1.0" label shown in the debug panel when no edition is set.
- zh-cn: 移除调试面板在未设置版本时显示的占位标签「OFFLINE EDITION · 1.0」。

## 0.3.1
- en: Fixed animation timing on low frame-rate displays and fixed an interaction that could stay stuck after the wallpaper pauses or hides.
- zh-cn: 修复低帧率显示下的动画节奏，并修复壁纸暂停或隐藏时交互可能残留卡住的问题。

## 0.3.0
- en: Added a UI language setting; the wallpaper title now follows the selected panel language.
- zh-cn: 新增界面语言设置，壁纸标题随所选界面语言同步切换。

## 0.2.0
- en: First release of the shared runtime: Spine animation, dialogue playback with subtitles, voice and BGM, configurable settings, logging, and the desktop debug panel.
- zh-cn: 共享运行时首发：Spine 动画、带字幕的对话播放、语音与 BGM、可配置设置、日志与桌面调试面板。
